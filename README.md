# 漢方薬検索アプリ｜PMDA XML 全128処方版

元のExcel「Dr.ゴクウの漢方一覧_修正版.xlsx」の128処方と、2026年10月29日に提供されたPMDA一括ダウンロードXML内のツムラ医療用漢方エキス製剤128件を照合して統合しました。

処方名・よみ・ツムラ番号・構成生薬名（漢字・カタカナ）から検索できます。詳細ボタンを押さず同一ページに配合量を表示します。

配合生薬量は **PMDA 電子添文 3.1 組成**にある製剤の1日量相当の原生薬量です。製剤量やエキス量とは区別します。

## GitHub Pages公開
解凍した8ファイルをリポジトリ直下へアップロードし、Settings > Pages > Deploy from a branch / main /(root) にします。旧版PWAのキャッシュに注意し、更新後は再読み込みしてください。

## 注意
* 他メーカーでは構成生薬・配合量・製剤量が異なる場合があります。
* Excel由来の解説文は未監修です。公開する場合には著作権・転載許諾を確認してください。
* PMDA情報は2026-10-29取得のスナップショットで、最新の電子添文の確認が必要です。
