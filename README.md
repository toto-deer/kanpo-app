# 漢方薬検索アプリ

スマートフォン・PC対応の静的Webアプリ。ツムラ処方番号、漢字、ひらがな、カタカナおよび文字列の一部で128処方を検索できます。データの解説は提供されたExcelに由来します。

## GitHub Pagesで公開する

1. GitHubで新しい **Public** リポジトリ（例：`kampo-search`）を作成します。
2. このZIPを解凍し、`kampo-search` フォルダー**内のファイルすべて**をリポジトリのルートにアップロードし、コミットします。
3. **Settings → Pages → Build and deployment → Deploy from a branch** を選択。Branch は **main**、Folder は **/(root)** を選んで Save。
4. Pagesに表示されたURLへPCまたはiPhoneでアクセスします。iPhoneで共有メニューから「ホーム画面に追加」もできます。

## ローカル確認

`index.html`をダブルクリックするだけでは`data.json`を読み込めないブラウザがあります。Pythonが使える場合、このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。公開後の利用者にはPythonは不要です。

## データについて

- 128処方をExcelから抽出。欠番は除外しました。
- 処方の読みがなは検索用途の編集データです。名称・読みの最終校正を推奨します。
- 構成生薬のg数は**確認済みの製品だけ**掲載：TJ-059の出典は[ツムラ公式漢方服薬メモ](https://medical.tsumura.co.jp/products/059/pdf/059-memo.pdf)です。未確認分は表示せず公式製品一覧へ案内します。
- Excelの解説は医療情報として校閲されていません。医療判断には最新の電子添文・公的資料を参照してください。
- 他メーカーでは配合生薬・配合量等が異なる場合があります。
- GitHubで公開すると、提供されたExcel由来の解説本文も公衆に公開されます。**公開前に著作権・転載許諾の確認が必要です。**
- 患者情報を保存・送信する機能はありません。
